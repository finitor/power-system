# Software

This directory is for Raspberry Pi software.

Suggested subprojects:

- `pi-controller/`: hardware adapters, service orchestration, and control logic.
- `telemetry/`: telemetry schemas, MQTT topics, and storage helpers.
- `dashboard/`: local dashboard or Grafana-related code.
- `services/`: system service wrappers and shared runtime utilities.

Keep control logic small, explicit, and easy to test.
