# Telemetry

Document telemetry names, units, and topics here.

## MQTT Topic Sketch

| Topic | Unit | Description |
|---|---:|---|
| `power/battery/voltage` | V | Battery voltage |
| `power/battery/current` | A | Battery current |
| `power/battery/soc` | % | Battery state of charge |
| `power/battery/temperature` | C | Battery temperature |
| `power/solar/power` | W | Solar charging power |
| `power/inverter/state` | state | Inverter status |
