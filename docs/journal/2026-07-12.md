# 2026-07-12

## Refrigeration gets a dedicated Load row

Moved refrigeration telemetry out of the three whole-system Load values. All
four display paths now put one `Refrigeration` row at the bottom of the Load
group, formatted as:

```text
Now 87W  3hr 100W  Cumulative 0.5kWh
```

This is easier to scan and makes the semantic boundary clearer: refrigeration
is a measured subset of the inverter load, while the other rows remain
whole-system estimates. Terminal, API-terminal, browser, and Kindle renderers
share the exact value formatter and tests assert both the new row and removal
of the old parenthetical annotations.
