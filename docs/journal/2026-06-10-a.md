# 2026-06-10 — Public release

The repo went public today (MIT license) after a preparation pass.

## Public-repo preparation

- All environment specifics left the tip and then the history: systemd
  units and the desktop entry became `@OFFGRID_USER@`/`@PROJECT_DIR@`
  templates rendered by deploy.sh from `id -un` and the checkout location;
  scripts derive their own paths; site coordinates moved to
  `/etc/offgrid-power.env` (never tracked). Public location granularity is
  "near Wawa, Ontario, Canada" — enough for the solar-noon and climate
  notes.
- `git filter-repo` passes rewrote all history: username and home paths to
  placeholder forms, coordinates and locator codes to approximations,
  author identity to the GitHub handle and noreply address. Verified zero
  hits for every pattern across every revision; both clones re-pointed and
  configured so future commits stay clean.
- One self-inflicted lesson: the first templated deploy failed because the
  self-update guard correctly ran the *old* deploy.sh, which installed the
  new templates verbatim without rendering. When a deploy changes deploy.sh
  and the configs it installs, run it twice.

## Hardware records normalized

Four overlapping documents (bom.csv, on-hand.csv, the inventory table, the
shopping list) had drifted — the Magnum adapter appeared in three states.
Now `hardware/inventory.csv` is the single source of truth (stable ids, one
status lifecycle: needed → ordered → on-hand → installed → deferred →
retired) and `scripts/shopping-list.py` is the procurement view as a
filter, so no second list exists to drift. Long-form rationale moved to
subsystem docs; `docs/hardware-inventory.md` keeps the format reference and
a refreshed Device Interfaces table.

Reconciliations recorded: Orion-Tr IP43 48/12 installed; Mean Well
DDR-60L-5 (48 V→5 V) on hand; both array-1 controllers ordered with the
EPEver TEP10425 the probable pick on PV-voltage headroom (Victron only if
its control/telemetry prove significantly better); the Waveshare RS485
adapter is for EPEver Modbus comms, the battery-RS485 fallback idea is
dead; Classic Modbus is a read *and write* path (taper).
