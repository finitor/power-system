# 2026-07-13

## Hide unreachable refrigeration telemetry

Changed the Tasmota snapshot policy so a failed current poll no longer carries
the S31's last-good value into the live display snapshot. Refrigeration is
optional appliance-level context, and a stale wattage looked too much like a
current measurement. The dedicated Refrigeration row now disappears from the
terminal, API-terminal, browser, and Kindle displays on failure and returns
after the next successful five-second poll.

This changes only live presentation. Previously recorded `tasmota.refrigeration`
samples remain in SQLite, so outages do not erase history or the rolling-average
seed used after recovery/restart.
