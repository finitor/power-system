# 2026-07-18

## Array 0 wiring fault found and corrected (~13:45)

Discovered that one array 0 panel was disconnected, and the remaining seven
panels were most likely wired as **4s ∥ 3s** rather than the intended 4s2p —
and had been for at least the whole 2026-06-20..07-02 calibration window that
the power-budget model was built on. Corrected to the intended 4s2p today.

Why the fault cost almost exactly one panel's worth: a 3s string (Voc
~135 V) paralleled onto a 4s string (Vmp ~144 V) pushes the Classic's global
MPP down to ~108 V, where both strings conduct at near-full current — the
composite array delivers about 7/8 of intended output rather than collapsing
further. (Had the MPPT instead parked at the 4s string's 144 V, the 3s
string would have sat beyond its Voc contributing nothing, and output would
have been closer to half.)

Model impact ([power-budget.md](../power-budget.md) updated, scenarios
re-run): array 0's calibrated 1.27 W per W/m² characterized the faulted
array; going forward expect ≈ 1.27 × 8/7 ≈ **1.45** (~60% of nameplate —
respectable for its age, and it retires the suspicion that array 0 itself
was underperforming). Notable scenario shifts:

- No-fridge occupied winter now rides through **all nine simulated winters
  at both PR bracket ends** (previously one empty event in the worst
  corner).
- The double-fault unattended corner (array 1 failed + 1.5× heater duty)
  collapses from 37 dead days to 4 — array 0 alone nearly carries the lean
  stack through stressed winters now, further weakening the case for
  battery expansion as insurance.
- Full-occupancy winter deficit trims to ~165–215 kWh; still structural.

Follow-up added to open measurements: recalibrate with
`scripts/calibrate_pv.py 2026-07-19` after a week of corrected wiring —
the slope landing near 1.45 confirms the 7/8 mechanism; materially lower
means array 0 has other losses and the scenario numbers walk back.

## Array 1 decommissioned for mount construction (until ~Sep 2027)

Array 1 taken out of service pending mount construction, expected complete
around **September 2027**. Final configuration plan: 3s4p (unchanged), 45°
tilt, on a **cabin rooftop** — same 3-wide × 4-high footprint as the ground
dry run, ~10 ft higher, with slightly reduced shading expected from the
height. The 2026-07-02 AR shading survey becomes a conservative floor;
re-survey from rooftop height when access allows.

Model consequences ([power-budget.md](../power-budget.md), interim section
added): winter 2026–27 runs on array 0 alone (~1.5 kWh/day darkest-week
potential at the corrected coefficient). Occupied modes need the generator
(full load ~46 sessions/winter; even no-fridge ~10). **Lean unattended
caretaker mode remains viable on array 0 alone** — median worst week
+0.8 kWh, zero bank-empties across nine simulated winters at nominal heater
duty — but the margin is thin against heater-duty error, which makes this
winter's heater-duty logging urgent rather than optional.
