# 2026-07-20

## Read-only SQLite opens can still break WAL ownership

A `mode=ro` Python query of the live metrics database, run as the operator,
created `metrics.sqlite-wal` and `metrics.sqlite-shm` as `tvetter:offgrid` mode
0644. The inherited ACL's group entry was present but its effective mask was
read-only, so the `offgrid` supervisor reported `attempt to write a readonly
database` and switched to the SD fallback. The degraded notifier correctly
alerted after its 120-second debounce. Restoring both sidecars to
`offgrid:offgrid` mode 660 recovered the primary without a restart and merged
2,180 samples plus 5 events from fallback; no telemetry was lost.

This corrects the July 19 conclusion that setgid plus a default group-write ACL
was sufficient. SQLite can narrow the inherited ACL mask according to its file
creation mode. All live-database opens, including read-only queries, must run as
`offgrid`. The query helper now enforces database-owner access, uses `mode=ro`
instead of `immutable=1`, and can create a consistent snapshot for long or
repeated analysis. Diagnostics also run SQLite explicitly as `offgrid` rather
than root.

## Refrigeration utilization from combined power tiers

Analyzed 13,533 one-minute `tasmota.refrigeration/power` samples covering
233.6 hours from local 2026-07-10 19:06 through 2026-07-20 12:56. The branch
feeds two identical cube freezers, one at deep-freeze temperature and one on an
external refrigerator-temperature thermostat. No temperature data was needed:
the histogram separated cleanly into ~1 W idle, 50–56 W lower-compressor,
70–75 W higher-compressor, and 115–130 W both-running tiers. Thirty-two startup
samples at ≥150 W were classified from their neighboring stable state.

Time occupancy was 50.0% idle, 40.5% lower-only, 5.4% higher-only, and 4.1%
both. That yields 44.6% duty for the lower-power compressor, 9.5% for the
higher-power compressor, and 27.1% capacity-normalized duty across the two-unit
system. Across the nine complete local days, median duties were 45.4%, 9.4%,
and 27.7%, respectively; the system result ranged only 25.0–28.1%. Median
cycles were ~9.3 min on / 11.5 min off for the lower-power unit and ~3.1 min on
/ 27 min off for the higher-power unit.

The likely mapping is lower-power/high-duty = deep freezer and
higher-power/low-duty = converted refrigerator, because warmer evaporator
operation can raise suction density, refrigerant mass flow, and running watts
while requiring far less runtime. The combined meter cannot prove that mapping;
a one-at-a-time test can.

Mean measured branch power was 32.1 W, or ~0.77 kWh/day—far below the earlier
pre-meter allocation of ~2.6 kWh/day. The full-occupancy power-model baseline
remains measured and valid, but its “no refrigeration” scenarios used the old
2.6 kWh/day subtraction and are now marked for recalculation.
