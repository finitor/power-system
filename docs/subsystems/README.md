# Subsystems

This folder is the project map by physical subsystem. Each page should answer the same practical questions:

- What hardware is installed?
- What telemetry should be collected?
- What control actions are allowed, if any?
- What wiring, protection, and communications details are known?
- What questions still need research or field verification?
